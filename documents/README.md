# documents/

Drop your own material here before running `/phd-hunter setup`: academic CVs,
motivation or cover letters you wrote, thesis or thesis summary, research
proposals, transcripts, diploma supplements. PDF, DOCX, Markdown or text.

Nothing in this folder is committed (it is in `.gitignore`) and nothing is
uploaded anywhere by the scripts. `python3 scripts/extract_docs.py` turns the
files into plain text under `documents/.extracted/` so setup can read them.
